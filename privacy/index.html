Privacy Policy

rclone Omarchy is a personal application used only by its owner to synchronize files between Google Drive and a Linux computer.

Google Drive access

The application requests access to Google Drive only for file synchronization operations requested by the owner, including reading, creating, modifying, moving and deleting files.

Data storage

rclone Omarchy does not operate an external server and does not collect or store Google Drive file contents on any third-party service operated by the application owner.

OAuth credentials and synchronization configuration are stored locally on the owner's Linux computer by rclone.

Data sharing

Google user data is not sold, shared, transferred or disclosed to third parties by this application.

Revoking access

Access can be revoked at any time from the Google Account security settings.
